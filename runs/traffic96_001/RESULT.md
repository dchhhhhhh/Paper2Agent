# iTransformer 在 Traffic 上的第一次端到端运行

**测试 MSE 为 0.4880739101**，采用训练集拟合的逐变量标准化尺度。控制程序读取现有任务卡和论文选页，调用模型提取实验规格，再调用模型生成可执行的 PyTorch 模型。冻结生成源码与 CPU 配置后，训练程序遍历全部训练窗口，按验证 MSE 选择检查点，对全部测试窗口计算指标。

| 实际运行项 | 结果 |
| --- | --- |
| 训练 | 10 轮，每轮 12,089 个窗口。批次大小 32，每个训练窗口随机抽取 172 个变量。 |
| 模型 | 23,360 个可训练参数。宽度 32、两层、两头，前馈宽度 64。注意力沿变量维计算。 |
| 验证 | 每轮 1,661 个窗口，全部 862 个变量；第 10 轮验证 MSE 最低，为 0.4369258276。 |
| 测试 | 3,413 个窗口 × 96 个未来时间步 × 862 个变量，共 282,432,576 个标量。平方误差和为 137,847,971.7082347。 |
| 独立复算 | 从 CSV 的前 12,280 行重新拟合标准化参数，重建的 3,508 行测试真值与保存的真值逐元素一致。NumPy 从预测与真值复算 MSE，与训练程序的差值为 1.11 × 10⁻¹⁶。 |
| 运行时间 | 训练、逐轮验证、最终测试与预测保存共约 8 分 22 秒。 |

ReproduceBench 作者报告的参考 MSE 为 0.4008。本次 MSE 高出 0.08727，按课程的“绝对差除以本次实测值”口径，差距为 17.88%。本次采用 CPU 窄模型、单个随机种子和作者公开的 Traffic CSV / 数据加载器。与 ReproduceBench 整包的逐文件一致性仍待核对；本次比较不能区分不同配置各自的影响。[基准论文附录表 7](https://aclanthology.org/2026.acl-long.1001.pdf#page=13)
